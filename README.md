# 🛒 Sistema de Loja Virtual – GeneXus 18

Este projeto consiste no desenvolvimento de um **Sistema de Loja Virtual**, criado como parte do meu aprendizado e prática com **GeneXus 18**, durante o curso de **Tecnólogo em Sistemas para Internet**.

O sistema simula o funcionamento de uma loja online, permitindo o gerenciamento de **produtos, estoque, vendedores e pedidos**, semelhante a sistemas utilizados em empresas para controle comercial e organização de processos de vendas.

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto foi:

- Aplicar conceitos de **modelagem de dados**
- Desenvolver **regras de negócio**
- Utilizar **transações, procedures e web panels**
- Praticar o uso do **GeneXus 18** em um cenário próximo a sistemas utilizados em empresas

---

## ⚙️ Funcionalidades Desenvolvidas

- 📦 Cadastro de produtos  
- 📊 Controle de estoque  
- 🛒 Registro de pedidos  
- 👤 Cadastro de vendedores  
- 💰 Cálculo de comissão por vendedor  
- 🧾 Gerenciamento geral da loja  

---

## 💡 Habilidades Demonstradas no Projeto

- Modelagem de banco de dados  
- Estruturação de sistema de vendas  
- Desenvolvimento de regras de negócio  
- Organização de dados de produtos, pedidos e vendedores  
- Implementação de lógica para cálculo de comissão
